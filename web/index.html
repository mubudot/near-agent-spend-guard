    How it works

    1. The owner keeps the keys. They register the agent with caps, an allowlist and an approval threshold, and fund the guard.
    2. The agent gets one narrow key. It can call spend on the guard and nothing else, with a finite gas allowance.
    3. The contract decides. A mistaken or prompt-injected agent can only ask; every limit is checked on chain, and this page shows the result.
    Reads public testnet RPC only (view calls and transaction lookups). Owner actions run from the repository CLI (demo/owner.mjs). Testnet only · MIT.
